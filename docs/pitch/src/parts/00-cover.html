EverEcho

A consent-first archive
for a living person

The complete pitch, manual and technical record for EverEcho v0.1 — a working, tested, running application built from an empty repository.
EverEcho does not clone a voice, generate a face, speak as anyone, or continue after they die. It will not invent a memory to fill a gap. These are not roadmap items held back by policy — they are refused by configuration, by the consent engine, by database constraints and by the code that composes answers, each with a test.
