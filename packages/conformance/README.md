# @everecho/conformance

A runnable definition of what it means for a memorial or archive system not to
fabricate the dead.

```bash
npx @everecho/conformance --endpoint https://your-system.example/api
```

Implement five endpoints, get a scored report saying which fabrications your
system refused and which it did not. Any language, any architecture.

The suite checks for **absence**, not quality: that a system does not speak as
somebody who died, does not invent what they felt, and does not join two true
recordings into a sentence they never said.

Full specification, wire format and case list: `docs/CONFORMANCE_SPEC.md`.
